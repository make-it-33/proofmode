# Design approval gate

No production visual, interaction, motion, illustration, image, video, audio, or marketing-creative implementation begins until the owner explicitly approves a presented direction.

## Approval pack

Each meaningful design phase must present:

1. **Problem and audience** — the user, moment, friction, desired action, and success signal.
2. **Experience principles** — the intended feeling and behaviors to avoid.
3. **Competitive/reference audit** — what is useful, overused, confusing, or differentiating.
4. **Two or three credible directions** — not cosmetic color swaps; each needs a rationale and trade-offs.
5. **Core journey** — information architecture and the main path before detailed polish.
6. **Key screens and states** — desktop/mobile plus loading, empty, error, timeout, offline, recovery, and completion where relevant.
7. **System proposal** — typography, color, spacing, surfaces, icons, illustration, data visualization, and reusable components.
8. **Motion and media plan** — purpose, storyboard, trigger, duration, easing, reduced-motion fallback, file format, loading strategy, licensing/provenance, and performance budget.
9. **Accessibility and trust** — contrast, focus, semantics, touch targets, cognitive load, answer-neutral evidence styling, and non-visual alternatives.
10. **Exact scope for approval** — what will be built now, what remains exploratory, and what will not change.

## Approval states

- **Exploration:** research only; not approved for production.
- **Approved with changes:** implement only after the requested changes are reflected in the scope.
- **Approved:** implementation may begin for the shown scope.
- **Rejected:** preserve findings, do not implement the direction.

## Media quality rules

- Images, animation, and video must clarify the product, create emotion, or improve comprehension—not decorate empty space.
- Prefer original or properly licensed assets with recorded provenance.
- Use responsive modern formats and explicit size/performance budgets.
- Never let motion obstruct evidence, imply truth before submission, or make competitive play unfair.
- Every essential video needs captions/transcript; every meaningful image needs appropriate alternative text; every animation needs a reduced-motion alternative.

## Post-approval verification

Compare implementation against the approved pack, capture desktop and mobile evidence, run accessibility and performance checks, document deviations, and request renewed approval for material changes.
