# Superseded competition explorations

Competition is removed from the active ProofMode product and V1/V2 roadmap by ADR 0008.

Historical Arena, scoring/rating, challenge, ladder, leaderboard, matchmaking, season, and public-comparison documents may remain in git history or as explicitly marked compatibility records. They are useful only for understanding rejected directions such as answer-revealing UI, fabricated cohort metrics, guide-heavy screens, and pressure mechanics.

Do not implement or link them as future product work. Current authority is root `AGENTS.md`, the canonical product/page/roadmap specs, approvals, quality bar, and `docs/handoff/`.
