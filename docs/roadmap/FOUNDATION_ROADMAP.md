# Foundation roadmap

## Phase 0 — foundation (current)

Repository governance, agent instructions, CI/security baseline, mission contract, deterministic scoring spike, corrected product rules/architecture, and researched backlog.

Exit: fixtures pass, one mission is unambiguous on paper, and the vertical-slice contract is agreed.

## Phase 1 — trustworthy vertical slice

Guest/auth path, immutable registry, one production mission, trusted event log, bounded AI gateway/mock, evidence-linked submission, deterministic explanation, replay/result card without fake percentiles, accessibility/security/telemetry/E2E.

Exit: 20 blind players; ≥80% agree scoring is fair; no answer cues or known exploits.

## Phase 2 — reusable game platform

Five mechanic renderers, content studio/QA workflow, 10–15 excellent missions, provisional skill profile, cost/performance budgets.

## Phase 3 — social retention

Daily scheduling, same-version challenges, decision-difference replay, seasons/leagues/streaks/notifications with anti-abuse, data-backed share cards.

## Phase 4 — paid value and hardening

Professional packs, deep replay, weakness analysis, billing/entitlements, deletion/export/support/incident tooling, security/load/backup/privacy readiness.

Consider native only after web retention, notification value, and a mobile-specific need are proven.
