# Agent Arena direction v1 — superseded historical record

- Original date: 2026-08-18
- Current status: **Superseded; do not implement**
- Superseded by: owner no-competition decision, 2026-08-28; ADR 0008

This document formerly explored a competitive teen AI-skill experience. Its production implementation was never accepted, and competition is now removed from the active product and V1/V2 roadmap.

Retained learning: evidence must be inspectable; AI moves are fallible; verification changes the learner’s understanding; recovery is first-class; desktop/mobile need intentional compositions; no pre-submit answer cues; no fake ranks/metrics.

Rejected: Arena framing, PvP, rank, leaderboard, matchmaking, comparison pressure, game-first identity, guide-heavy/text-heavy/childish execution, and future implementation of this direction.

Current authority: `AGENTS.md`, ADR 0008, canonical product/page/roadmap specs, and `docs/handoff/`. Full original content remains available in git history.
