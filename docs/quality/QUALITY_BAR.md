# Quality bar

## UX

A new player can explain the objective/next action within 20 seconds. Primary actions need no tutorial. Async operations have loading/success/empty/timeout/offline/recovery. Keyboard/screen-reader flows are complete. Motion is purposeful and reducible. No overlap, clipping, tiny text, or accidental horizontal scroll.

## Game/scoring

Truth and alternatives documented; strong/weak/exploit/ambiguous fixtures; scores reproduce; explanations match engine facts; comparative claims use real comparable cohorts.

## Engineering

Tests cover domain/regressions; observability locates failures without unnecessary private text; performance budgets exist; security matches the threat model; rollout/rollback are documented.

## Content

Data is consistent and fictional; distractors plausible; feedback teaches transferable process; editorial/accessibility review complete.
