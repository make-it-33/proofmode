# ADR 0001: Web-first PWA before native apps

- Status: accepted
- Date: 2026-08-15

ProofMode must validate mission enjoyment, scoring trust, and retention before paying for separate native clients. Build a responsive web/PWA first and keep domain contracts transport-independent. Prioritize responsive evidence workflows, share links, installability, and one fast iteration surface. Revisit native after repeat use and mobile-specific needs are measured.
