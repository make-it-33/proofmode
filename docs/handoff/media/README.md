# Handoff visual maps

These source-reviewable SVGs summarize the product without pretending that planned interfaces are implemented.

- `proofmode-product-map.svg` — product surfaces, learning loop, V2 gates, and removed competition.
- `proof-chain-walkthrough.svg` — a restrained animated Proof Chain; reduced-motion users see the complete static sequence.
- `v1-v2-roadmap.svg` — dependency order from the current lesson to connected V2 capabilities.

They are documentation assets only. Do not import them into the production app without a page need, accessibility review, provenance confirmation, and performance measurement.
